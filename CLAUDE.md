# Заметки для работы над игрой

- Язык интерфейса и общения с автором (Artem): русский.
- Сборка: `node build.mjs` -> `dist/index.html`. Перед PR собрать и прогнать игру в браузере (все уровни открываются, нет ошибок в консоли).
- Код без модулей и без зависимостей: файлы склеиваются в один `<script>` в порядке из `build.mjs`. Функции видны глобально.
- Уровень = файл в `src/levels/<эпизод>/` с `LEVELS.push({...})`. Сцены рисуются в `src/scenes/`.
- Стиль: мультяшный, толстый контур `INK`, функции `toon/rr/ell/circ`. Без рогатки. Средство выбирается кнопкой, целятся пальцем.
- Дизайн и план развития: `docs/design.md`. Обучение спрятано в механику, главное фан и желание перепроходить.
- Уровни делаются вручную из готовых деталей, процедурный генератор автор не хочет.
- Языки: русский, английский, испанский. Тексты пишутся по-русски прямо в уровнях и сценах, перевод лежит в `src/i18n/en.js` и `src/i18n/es.js` (ключ = русская строка). Текст на холсте, `say()` и подписи переводятся сами; строки с подстановкой писать через `tl('... {0} ...', x)`, не через шаблон `${}`. После правки текстов: `node tools/i18n-check.mjs` (должно быть 0 пропусков).
