# Как это потушить

Браузерная игра: перед игроком горит предмет, и надо понять, чем и как его потушить.
Мультяшный стиль, карта эпизодов, звёзды, короткие уровни с одной сценой.

## Запуск

```
node build.mjs
```

Собирает всю игру в один файл `dist/index.html`. Его можно открыть в браузере напрямую, без сервера.
Зависимостей нет, нужен только Node.js 18+.

## Структура

```
src/
  index.html          разметка экранов (стили и код вставляются при сборке)
  style.css           стили интерфейса
  engine/             движок: общие функции, средства тушения, звук, экраны, игровой цикл, огонь
  scenes/             отрисовка сцен (фоны и предметы), одна сцена может служить нескольким уровням
  levels/
    registry.js       список LEVELS и EPISODES
    dom/              эпизод 1 «Дома»: по файлу на уровень (01-log.js ... 08-gas.js) и map.js
    dacha/            эпизод 2 «Дача»: костёр, мангал, баня, сарай, пал травы, труба, баллон, веранда
build.mjs             сборка в один HTML
docs/design.md        дизайн игры и план развития
```

## Как добавить уровень

1. Нарисовать сцену в `src/scenes/<сцена>.js` (функция фона `bgXxx(c)` и функции предметов `drawXxx(it)`), или взять готовую.
2. Создать `src/levels/<эпизод>/NN-<id>.js` с `LEVELS.push({ ... })`. Образец: любой уровень из `levels/dom/`.
3. По желанию: `treasure` (кого или что спасти) и `medals` (медали за умное прохождение), описание в `src/engine/extras.js`.
4. Добавить координаты кружка на карте в `levels/<эпизод>/map.js`.
   Новый эпизод: папка `levels/<id>/`, в её `map.js` вызов `episode({ id, name, bg, map })`, и id в списке `EPISODES` в `build.mjs`.

Что ещё умеет уровень (кроме `hot`, `tick`, `done`, `live`, `drag`):
- `cls: 'B'` у предмета: горящая жидкость, вода её разбрызгивает (`spillMsg`), песок тушит лучше.
- `cls: 'C'` у предмета: струя газа, обычными бросками не тушится, решает `gasHit(G, it, tool)`.
- `soakFree`, `soakTime` у предмета: вода на нём не ущерб, а мокрая полоса, через которую огонь не идёт.
- `safe` у предмета: огонь на него не перекидывается (сложенный зонт).
- связь `[a, b, скорость, обратно]`: ветер, обратно = множитель скорости от b к a; `linkOk(G, a, b)` может связь отключить.
- `landed(G, th, p)`: свой ответ на попадание (пар на каменке, охлаждение баллона); `init(G)`: своё состояние уровня.
5. `node build.mjs` и проверить в браузере.
