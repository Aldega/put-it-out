# «Огненное сопло» v2 — планировка и требования к сцене

## Концепция
Ночной полигон огневых испытаний метанового ракетного двигателя. Игроки стартуют в защищённом бункере (пульт + остеклённый наблюдательный фасад), видят работающий двигатель и возгорание турбонасосной зоны. Авария устраняется дистанционно; наружный выход свободен, но опасная зона обозначена. Отдельно защищают кабели, сухую степь и корову.

## Система координат
Roblox studs; локальное начало полигона (0, 0, 0), мировое смещение **(0, 0, 440)** — чтобы не пересекаться с трассой Ф-1. Ось **+X** направлена от бункера к соплу и степи; **+Z** — в сторону техзоны; **Y** — высота. Точность позиционирования в Roblox Studio нужно проверить.

| Зона | Локальные габариты / центр | Назначение |
| --- | --- | --- |
| A. Бункер | X -82..-42, Z -41..-8 | Отдельная точка входа, пульт, панорамное окно по восточному фасаду (X=-43); дверь с южной стороны (Z=-9) |
| B. Площадь и маршруты | X -65..0, Z -10..35 | Выход из бункера, безопасный проход, разметка опасных зон, перила и знаки |
| C. Стенд | X -18..70, Z -35..15; двигатель ~(10,8,-8) | Рама, агрегаты, сопло, факел +X, дренаж и отвод струи, водяная рампа |
| D. Техзона | X -35..35, Z 17..58 | Баллоны N2, насосный блок, шкафы, инженерные линии, склад |
| E. Степь | X 60..115, Z -45..55 | Сухая трава, пожарный фронт, лафет (~46,3,18), корова (~86,4,25) |
| F. Периметр | ~X -118..122, Z -95..96 | Забор, ворота, прожекторы, возвышенности, дальний силуэт |

## Схема сверху (не в масштабе)
```text
                                +Z  техзона
                               ↑
             ┌───────────────────────────────────────────────┐
             │  D: N2 / шкафы / техпроезд        E: степь    │
             │   ◉◉◉      ▣                     ♒ лафет  🐄   │
             │              ┌─── C: стенд ────────→ сопло   │
             │              │ двигатель ════════>> факел     │
             │ A: бункер    └─── охлаждение / кабели         │
             │ ┌─────────┐                                  │
             │ │ пульт   ║ окна в сторону стенда             │
             │ │         ║                                  │
             │ └── дверь ┘───────── B: проход                │
             └───────────────────────────────────────────────┘
                 -X                                 +X →
```

## Геометрия и доступность
- Бункер: фундамент, задняя и боковые стены, смотровые стеклопакеты в восточном фасаде, верхняя металлическая ферма, фасадная дверь по южной стене **со свободным проёмом**. Все стеклянные панели с коллизией, но ни одна не блокирует дверь.
- Навигация: непрерывный проход от spawn к двери, затем к стенду/техзоне. Пульт не пересекает зону спавна. Проход минимум 7 studs и высота >=7 studs.
- Сложные агрегаты — Anchored; мелкие болты, лампы, кабели, таблички, свет и эффекты — CanCollide=false и при необходимости CanQuery=false.
- Никаких невидимых коллайдеров в проёмах. Опасная зона читается по разметке, ограждениям и цвету.
- Пульт управляется из бункера, лафет физически снаружи, но имеет дистанционную кнопку на пульте.

## Игровые соответствия
| Визуальный элемент | Сценарная функция |
| --- | --- |
| Красная кнопка STOP | Перекрывает CH4/O2 и убирает тягу |
| Жёлтая кнопка N2 | После STOP проводит продувку и завершает этап тушения |
| Синяя DELUGE | Запускает водяную рампу, снижает огонь кабелей |
| Синяя CANNON | Дистанционный лафет, увлажняет степь |
| Красная SIREN | Корова покидает опасную зону |
| Освещение / дым / пар / факел | Визуальная телеметрия текущего состояния |
| Магистрали CH4, LOX, N2 | Цветовая идентификация систем (не свободный игровой выбор) |

## Приоритеты качества
1. Силуэт стенда должен читаться с окна бункера: насосный блок, камера, сопло, рама и коммуникации.
2. Интерьер бункера выглядит рабочим (панели, приборы, кабели, аварийные лампы), а не пустой коробкой.
3. Вторая глубина: складская техзона, периметр, грунт, отдельные источники света, холмы.
4. Технические детали не должны превращаться в препятствия.
5. Встроенные эффекты Roblox без внешних моделей и платных ассетов.

## Реализация
- `roblox/src/server/RocketScene.lua` — отдельный ModuleScript, создаёт геометрию, свет и VFX, отдаёт ссылки на ключевые объекты.
- `roblox/src/server/Rocket.server.lua` — управление миссией, условия победы/поражения, действия с пульта, обновление эффектов.
- `roblox/build.mjs` — вкладывает ModuleScript в `.rbxlx`.
- Игра на уровне F1 не изменяется; новая сцена создаётся только после выбора ракетной миссии и удаляется по завершении.

## Приёмка в Roblox Studio
- Spawn в бункере, свободный проход через дверь без прыжков/клиппинга.
- Из бункера видно двигатель; кнопки доступны; боковая стена/окна не блокируют пульт.
- STOP гасит факел; N2 создаёт продувку; DELUGE включает визуальные струи; CANNON влияет на траву; SIREN переносит корову.
- После миссии возвращается меню, следующее прохождение создаёт сцену заново, F1 запускается отдельно.
- Тест 1/2 игроков, ПК/телефон, отсутствие ошибок в Output, производительность и количество деталей.
