# «Как это потушить» в Roblox: прототип миссии «Авария Ф-1»

Отдельный проект на тему игры: 3D, кооператив, код на Luau. Веб-игру (`src/`) не трогает.

## Что внутри

- `build.mjs` собирает место Roblox в один файл `roblox/dist/kak-eto-potushit-f1.rbxlx`:
  сцена (трасса, гравий, шинный барьер, болид, пилот, пост маршалов, медики) задана деталями прямо в нём.
- `src/server/Mission.server.lua` логика миссии на сервере: огонь и его перекидывание, средства тушения,
  лампа батареи, кольцо «E», красный флаг, пилот, раунды и медали.
- `src/client/HUD.client.lua` интерфейс игрока и прицеливание струи мышью или пальцем.
- `src/shared/I18n.lua` переводы на английский и испанский (ключ = русская строка, как в веб-версии).
- `tools/check-lua.mjs` проверка без Roblox: синтаксис, опечатки в именах, все ли строки переведены.

## Сборка и проверка

```
node roblox/build.mjs
npm i --no-save luaparse && node roblox/tools/check-lua.mjs
```

## Как запустить в Roblox Studio

1. Файл → Открыть из файла (File → Open from File), выбрать `kak-eto-potushit-f1.rbxlx`.
2. Кнопка «Играть» (Play, F5).
3. Для кооператива: вкладка «Тест» (Test) → «Клиенты и серверы» (Clients and Servers), 2 игрока → «Старт».

## Миссия

Болид вылетел с трассы и врезался в шинный барьер. Мотор горит, течёт топливо, пилот в кокпите,
по трассе ещё несутся болиды. Средства: вода (пожарный щит), порошок и пена AFFF (у маршалов);
в руках один огнетушитель, так команда делит работу.

Нюансы: красный флаг останавливает гонку (иначе болид отбрасывает с трассы); вода на болид с красной
лампой бьёт током, а на горящее топливо разбрызгивает его; порошок быстро сбивает пламя, но мотор
вспыхивает снова, пока его не залили пеной; батарея поджигает мотор, пока болид не обесточен лампой
или кольцом «E»; шины, потушенные одним порошком, тлеют и вспыхивают, их проливают водой.
Пилот снимает руль и выбирается; если не помочь, выпрыгивает и убегает сам (никто не погибает).
Медали: «Сначала красный флаг», «Порошок, потом пена», «Пилот спасён», «Барьер не загорелся», «Без ошибок».
